Task 4: fitness and wellness

Cadence

Built on rhythm rather than accumulation. Most fitness apps are maximisers: a bigger number every week, an unbroken streak, and a quiet sense of failure when you miss a day. That pattern is exactly where these apps stop being wellness products, so this one is designed against it.

What is deliberately absent

No weight, no body composition, no calorie counting. Those are the features that turn a wellness app into something people use against themselves, and removing them costs this design nothing: movement, sleep, energy and consistency already answer the brief. If a reviewer asks, that is the answer, and it is a stronger one than a food diary would have been.

User flow

Today → Start session → Active → Log effort → Today, updated
Today → Week ribbon → Progress → Session history
Move → Pick a session → Active
Profile → Goal → Today reflects it

The rule: indigo is the only thing you can press. The four effort colours are data and report how hard a session was, nothing else. Red means hard, never wrong, which matters in an app where people are quick to read colour as judgement.

Type

  • Space Grotesk 600/700 for every number and heading. Tabular figures, so the live timer does not jitter as digits change.
  • Instrument Sans 400/500/600 for all supporting text.
  • Scale: 76 for the running timer, then 34 / 26 / 21 / 18 / 16 / 14.5 / 12.5 / 11.5.

Frames to build

  • Today : the three calls, train, easy and rest, since the card changes colour and copy in each.
  • Move : session library, plus the quick-log chips.
  • Active session : running and paused. The only dark screen in the app.
  • Log effort : the post-session sheet.
  • Progress : balance beam, six-week chart, activity split.
  • Profile : goals and preferences, with the streak toggle in both states.
